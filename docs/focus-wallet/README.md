# Cardputer Home + Focus Wallet

JST時計のロック画面、アプリ選択ホーム、Wi-Fi設定と、集中セッションで「自由時間」が貯まるポモドーロをまとめたCardputer向けアプリです。

設定値、報酬計算、日付変更、保存・復元の詳細は[ポモドーロ設定仕様](pomodoro-settings.md)を参照してください。
ロック画面、画面の自動消灯、Wi-Fi時刻同期の詳細は[端末動作仕様](device-behavior.md)を参照してください。

## 実装済み

- 起動時に表示するJST時計ベースのロック画面
- ロック画面から開く1ページ1アプリ式ホーム画面
- 画面全体をオフスクリーン描画して一括転送する、ちらつき抑制表示
- 30秒無操作後のバックライト減光と、2分無操作後の表示パネルスリープ＋ESP32-S3 Light Sleep
- 集中・休憩・自由時間の終了時にバックライトを通常輝度へ自動復帰
- 周辺Wi-Fiのスキャン、SSID選択、パスワード入力
- Wi-Fi認証情報の端末内保存と起動時の自動再接続
- ビルド時Wi-FiプリセットによるSSID・パスワードの事前登録
- 起動時と1時間ごとだけWi-Fiへ接続するNTP時刻取得（JST/UTC+9）
- Wi-Fi設定から切り替えられる常時接続モード
- 集中、短い休憩、長い休憩、自由時間の各タイマー
- 開始、一時停止、再開、キャンセル
- 規定回数達成時の自由時間付与
- 自由時間残高・残高上限・1日獲得上限
- 自由時間の秒単位消費
- 今日の完了回数、集中時間、獲得・使用時間と直近7日分の保存
- 設定・進捗・実行中タイマーのNVS（Preferences）保存
- RTC搭載機での電源断中経過時間の復元
- 完了時の内蔵スピーカー通知
- 全画面右上へのバッテリーアイコンと残量パーセント表示
- 自動休憩・自動集中、翌日繰り越し、サウンド設定
- 通常表情と、完了時・おみくじ結果の笑顔を`drawCompanion()`で切り替える

## 操作

### ロック画面

| キー | 動作 |
| --- | --- |
| `ENTER` / `SPACE` | アプリ選択ホームを開く |

30秒間キー操作がないとバックライトを輝度120から20へ下げ、2分間操作がないと表示パネルをスリープさせてESP32-S3もLight Sleepへ移行します。減光中は、キー入力で画面を明るくすると同時にその操作も実行します。Light Sleep中の最初のキー入力はCPUと画面の復帰だけに使います。集中・休憩・自由時間の終了時は、内部タイマーで復帰して通常表示へ戻ります。Wi-Fi動作中はLight Sleepを保留し、Wi-FiがOFFになった時点で移行します。

### アプリ選択ホーム

| キー | 動作 |
| --- | --- |
| `←` / `→` | 前／次のアプリページへ移動 |
| `↑` / `↓` | 前／次のアプリページへ移動（同じ操作） |
| `ENTER` | 選択したアプリを開く |
| `1` / `2` / `3` | ポモドーロ／おみくじ／Wi-Fi設定を直接開く |
| `H` | ロック画面へ戻る |

### Focus Wallet

| キー | 動作 |
| --- | --- |
| `SPACE` | 集中開始／完了画面で次の休憩・集中を開始／実行中タイマーの一時停止・再開 |
| `X` | 実行中タイマーをキャンセル |
| `F` | 集中開始 |
| `B` | 休憩開始 |
| `U` | 自由時間を使う |
| `S` | 設定画面 |
| `D` | 履歴画面 |
| `H` | アプリ選択ホームへ戻る |
| `↑` / `↓` | 設定項目を移動 |
| `←` / `→` | 設定値を変更 |
| `ENTER` | 数値設定の直接入力を開始／確定 |
| `0`〜`9` | 直接入力中の数値を入力 |
| `DEL` / `TAB` | 入力末尾を削除／直接入力を取り消す |

直接入力は`ENTER`、数値、`ENTER`の順で操作します。直接入力値は確定時に保存され、左右キーによる変更は操作した時点で保存されます。実行中のタイマー時間は変わらず、次のセッションから新しい設定が使われます。

### おみくじ（OMIKUJI）

抽選すると候補とクリック音が高速で切り替わり、最後の10回で段階的に減速します。先に抽選した結果まで順番に進んで止まり、決定音を鳴らします。所要時間は約3秒を目安に、選択肢数と停止位置に応じて前後します。進捗バーは実際の回転に合わせて進み、停止と同時に完了します。SoundがOFFの場合は無音です。抽選中は連打・セット切替・設定変更を受け付けず、`H`で抽選を中止してホームへ戻れます。

設定を3セット保存できます。各セットの初期値は `yes` / `no` の二択です。各選択肢は同じ確率で抽選され、続けて同じ結果になることもあります。

| キー | 動作 |
| --- | --- |
| `SPACE` / `ENTER` | 抽選する／もう一度引く |
| `S` | 選択肢の設定を開く |
| `1` / `2` / `3` | 保存する設定セットを切り替える（抽選画面・設定画面） |
| `H` | ホームへ戻る（設定中は抽選画面へ戻る） |
| `↑` / `↓`（設定中） | 編集する選択肢を選ぶ |
| `←` / `→`（設定中） | 選択肢数を2〜20個に変更する |
| `ENTER`（設定中） | メッセージ編集を開始する |
| `ENTER` / `TAB`（編集中） | 保存／キャンセル |
| `DEL`（編集中） | 末尾の1文字を削除する |

メッセージは本体キーボードから英数字・記号を最大48文字入力できます。空欄または空白だけのメッセージは、1始まりの選択肢番号（`1`、`2`、…）で表示します。長い結果は画面幅に合わせて末尾を省略します。編集中は `H` や方向キー位置の記号も文字として入力できます。

選択肢数は変更時、メッセージは確定時に、現在のセットへ自動保存されます。3セットはそれぞれ独立して保存され、再起動時は最後に選んだセットを開きます。既存のおみくじ設定はセット1に引き継ぎます。編集中の `1` / `2` / `3` は文字入力として扱います。選択肢数を減らしても非表示になったメッセージは残り、再び増やすと復元されます。追加した未編集の選択肢は番号表示です。

### Wi-Fi設定

| キー | 動作 |
| --- | --- |
| `S` | 周辺ネットワークをスキャン |
| `↑` / `↓` | スキャン結果を選択 |
| `ENTER` | ネットワーク決定／パスワード保存・接続 |
| `DEL` | パスワードを1文字削除 |
| `TAB` | パスワード入力をキャンセル |
| `C` | 保存済みネットワークへ接続して時刻同期 |
| `A` | 1時間ごとの時刻同期／常時接続を切り替え |
| `X` | 接続・スキャンを中止、または切断 |
| `F` | 保存済みSSID・パスワードを削除 |
| `H` | アプリ選択ホームへ戻る |

## ビルド

Arduino IDEで次を選択します。

1. ボード: `M5Stack > M5Cardputer`
2. ライブラリ: `M5Cardputer`（依存するM5Unified/M5GFXを含む）
3. [`focus_wallet.ino`](../../src/focus_wallet/focus_wallet.ino)を検証してCardputerへ書き込む

## ファイル構成

画面ごとの表示処理とキー操作は、Arduino IDEで追いやすいよう個別ファイルへ分けています。

| ファイル | 担当 |
| --- | --- |
| `focus_wallet.ino` | 状態、タイマー、保存、Wi-Fi/NTP更新、setup/loop |
| `character_image.h` | 通常表情の埋め込みPNGと表情の選択 |
| `character_happy_image.h` | 完了時・おみくじ結果の笑顔PNG |
| `ui_common.h` | ヘッダー、フッター、文字収め、バッテリー、共通キー判定 |
| `screen_launcher.h` | アプリ選択ホーム |
| `screen_focus.h` | Focus Wallet／タイマー |
| `screen_settings.h` | ポモドーロ設定 |
| `screen_history.h` | 日別履歴 |
| `screen_result.h` | 集中・休憩・報酬の完了画面 |
| `screen_lock.h` | 起動時のJST時計ロック画面 |
| `screen_omikuji.h` | おみくじ抽選、選択肢数・メッセージ編集、保存 |
| `screen_wifi.h` | Wi-Fi状態、スキャン、パスワード入力 |
| `screen_router.h` | 描画先とキー入力先の画面切り替え |

各画面ファイルには、その画面の描画関数と入力ハンドラーをまとめています。新しいアプリ画面を追加する場合は、画面用ファイルを作り、`Screen`列挙と`screen_router.h`へルートを追加します。

確認済み環境:

- M5Stack ESP32 board package 3.3.9
- M5Cardputer ADV（Arduino IDEでは `M5Cardputer` ボードを選択）
- M5CardputerライブラリがADVを自動判別し、TCA8418キーボードを使用

Cardputer ADVの方向キー位置は、現在のライブラリでは `;`、`,`、`.`、`/` として読み取られます。本アプリではメニューや設定画面に限り、Fnを押さなくてもそれぞれ `↑`、`←`、`↓`、`→` として扱います。Wi-Fiパスワード入力中は通常の記号として入力できます。将来のライブラリが返す標準HID方向キーにも対応しています。

## ビルド時Wi-Fiプリセット

よく使うアクセスポイントは、`src/focus_wallet/wifi_presets.h`の配列へあらかじめ登録できます。このファイルはGit管理の対象外です。

```cpp
static const WifiPreset WIFI_PRESETS[] = {
    {"HomeWiFi", "your-password"},
    {"MobileHotspot", "your-password"},
};
```

保存済みネットワークがまだない場合は、起動時に先頭のプリセットへ自動接続します。Wi-Fiスキャンからプリセットと同じSSIDを選んだ場合も、パスワード入力を省略して接続します。複数の場所で利用する場合は、必要なSSIDを同じ配列へ追加してください。記述例は[`wifi_presets.example.h`](../../src/focus_wallet/wifi_presets.example.h)にあります。

この方式では認証情報がソースとファームウェアへ平文で埋め込まれます。`wifi_presets.h` を公開リポジトリへコミットしないでください。端末画面から入力した認証情報は従来どおりPreferencesへ保存され、そちらがプリセットより優先されます。

## 時計、Wi-Fi省電力動作、通知について

CardputerはiOSアプリと異なり、バックグラウンドで別プロセスとして動くOSを持ちません。本体の電源が入っている間は、別画面を表示していてもタイマーが進み、完了時に画面と音で通知します。

標準では起動時と前回の同期成功から1時間後だけWi-Fiへ接続します。NTPの同期完了通知を受け取るとRTCをJSTへ同期し、Wi-Fi無線をOFFにします。接続に失敗した場合は5分後に再試行します。

Wi-Fi設定画面で`A`を押して常時接続モードをONにすると、同期後も接続と自動再接続を維持します。設定はPreferencesへ保存されます。

初代CardputerでWi-Fiにも接続できず、電源断中の経過時間を確認できない場合は、不正な完了判定を避けるため残り時間を保持した一時停止状態で復元します。

## キャラクター画像

[`sample.png`](../../assets/focus-wallet/sample.png)から切り出した通常の表情は`character_image.h`、[`character-happy.png`](../../assets/focus-wallet/character-happy.png)から切り出した落ち着いた笑顔は`character_happy_image.h`です。どちらも全身画像から顔と上半身を52×64pxへ切り出し、透過PNGとしてフラッシュへ埋め込んでいます。SDカードは不要です。角・髪・顔が枠で切れないよう、キャラクター上端に少し余白を残しています。`character-happy.png`の背景は不透明な黒なので、埋め込み時に画面端とつながった黒だけを透過しています。

`drawCompanion()`が表情を選びます。集中・休憩・自由時間の完了画面と、おみくじの結果表示は笑顔です。待ち受け、抽選中、その他の画面は通常の表情のままです。

全身PNGから笑顔の埋め込みを作り直す場合（Pillowが必要です）:

```sh
python3 scripts/embed_companion.py \
  assets/focus-wallet/character-happy.png \
  -o src/focus_wallet/character_happy_image.h \
  --symbol character_happy_png
```
