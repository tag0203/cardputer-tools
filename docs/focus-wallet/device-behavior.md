# 端末動作仕様

この文書は、Cardputer版Focus Walletのロック画面、バックライト、Wi-Fi時刻同期に関する現在の仕様をまとめたものです。

実装の正本:

- 起動・Wi-Fi/NTP・バックライト: [`focus_wallet.ino`](../../src/focus_wallet/focus_wallet.ino)
- ロック画面: [`screen_lock.h`](../../src/focus_wallet/screen_lock.h)
- アプリ選択: [`screen_launcher.h`](../../src/focus_wallet/screen_launcher.h)
- Wi-Fi設定: [`screen_wifi.h`](../../src/focus_wallet/screen_wifi.h)
- 画面・入力ルーティング: [`screen_router.h`](../../src/focus_wallet/screen_router.h)

## 起動とロック画面

起動直後はアプリ一覧ではなく、スマートフォンのロック画面に相当する時計画面を表示します。

表示内容:

- JSTの時刻、秒、日付、曜日
- バッテリー残量
- 実行中タイマーのモードと残り時間
- Wi-Fi時刻同期モードの状態

`ENTER`または`SPACE`でアプリ選択ホームを開きます。ホームには次の2アプリだけを表示します。

1. Focus Wallet
2. Wi-Fi Settings

ホームで`H`を押すとロック画面へ戻ります。時計は独立したアプリとしては扱いません。

## バックライトの自動減光

最後のキー入力から2分経過すると、バックライト輝度を次のように変更します。

```text
通常輝度: 120
減光輝度:  20
```

- タイマー、時刻更新、Wi-Fi同期は減光中も継続します。
- 減光後の最初のキー入力は通常輝度への復帰だけに使います。
- 復帰に使ったキーのアプリ操作は実行しないため、見えにくい状態での誤操作を防ぎます。
- 復帰後、次のキー入力から通常の操作として受け付けます。
- 画面は消灯せず、暗い状態で表示を維持します。
- 集中、短い休憩、長い休憩、自由時間のいずれかが終了すると、自動的に通常輝度へ戻します。
- タイマー終了による復帰時点から、無操作2分の計測をやり直します。

## Wi-Fiの標準動作

初期設定は`MODE: HOURLY TIME SYNC`です。Wi-Fiは常時接続せず、以下のタイミングだけ有効にします。

1. 端末起動時
2. 前回のNTP同期成功から1時間後
3. Wi-Fi設定画面で`C`を押して手動同期した時
4. Wi-Fiスキャンや接続設定を操作している時

接続後はNTPサーバーへ問い合わせ、実際の時刻同期コールバックを受信してから次を行います。

1. システム時刻をJSTとして利用可能にする。
2. RTC搭載機ではRTCもJSTへ更新する。
3. 次回同期を1時間後に予約する。
4. Wi-FiとSNTPを停止し、無線をOFFにする。

時刻がすでに設定済みでも、NTPの同期通知を受け取るまでは同期成功扱いにしません。

### 接続失敗

- 接続開始から15秒でタイムアウトします。
- 標準モードではWi-FiをOFFに戻し、5分後に再試行します。
- スキャン結果が0件または失敗の場合も、標準モードではWi-FiをOFFに戻します。
- SSIDが未設定の場合、自動接続は行いません。

## 常時接続モード

Wi-Fi設定画面で`A`を押すと、次のモードを切り替えます。

```text
MODE: HOURLY TIME SYNC
MODE: ALWAYS CONNECTED
```

常時接続モードでは:

- NTP同期後もWi-Fiを切断しません。
- ESP32の自動再接続を有効にします。
- 接続が失敗した場合は5分後に再試行します。
- 設定値をPreferencesの`wifi_always`へ保存し、再起動後も維持します。

常時接続をOFFに切り替えると、その場でWi-Fi無線を停止し、次の周期同期を1時間後に予約します。

## Wi-Fi設定画面の操作

| キー | 動作 |
| --- | --- |
| `A` | 周期同期／常時接続を切り替え |
| `S` | 周辺ネットワークをスキャン |
| `C` | 保存済みネットワークへ接続して時刻同期 |
| `X` | 現在の接続または処理を停止 |
| `F` | 保存済みSSID・パスワードを削除 |
| `H` | アプリ選択ホームへ戻る |

ネットワーク一覧とパスワード入力の操作はREADMEを参照してください。

## タイマー復元との関係

RTCまたは信頼できるシステム時刻がある場合は、保存時刻との差から電源断中のタイマー経過を復元します。

RTCが利用できず、実行中タイマーを復元する必要がある場合は、起動時Wi-Fi同期を待ちます。15秒以内に信頼できる時刻を取得できなければ、不正な完了判定を避けるため残り時間を保持した一時停止状態で復元します。

## 実機確認項目

- 起動直後にロック画面が表示されるか。
- `ENTER`と`SPACE`でホームを開けるか。
- ホームに時計アプリが表示されず、2アプリ構成になっているか。
- 2分無操作後に暗くなり、最初のキーで明るさだけが戻るか。
- ポモドーロ実行中も減光され、タイマーが進み続けるか。
- 減光中に集中、各休憩、自由時間が終了すると、キーを押さなくても通常輝度へ戻るか。
- タイマー終了で明るくなった後、無操作なら2分後に再び減光するか。
- 標準モードでNTP同期後にWi-FiがOFFになるか。
- 1時間後に再接続して時刻同期するか。
- 接続失敗後、Wi-FiがOFFになり5分後に再試行するか。
- 常時接続ONで同期後も接続を維持するか。
- 常時接続設定が再起動後も維持されるか。
