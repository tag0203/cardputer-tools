# 端末動作仕様

この文書は、Cardputer版Focus Walletのロック画面、画面の省電力制御、Wi-Fi時刻同期に関する現在の仕様をまとめたものです。

実装の正本:

- 起動・Wi-Fi/NTP・画面の省電力制御: [`focus_wallet.ino`](../../src/focus_wallet/focus_wallet.ino)
- ロック画面: [`screen_lock.h`](../../src/focus_wallet/screen_lock.h)
- アプリ選択: [`screen_launcher.h`](../../src/focus_wallet/screen_launcher.h)
- Wi-Fi設定: [`screen_wifi.h`](../../src/focus_wallet/screen_wifi.h)
- 画面・入力ルーティング: [`screen_router.h`](../../src/focus_wallet/screen_router.h)

## 起動とロック画面

起動直後はアプリ一覧ではなく、スマートフォンのロック画面に相当する時計画面を表示します。

表示内容:

- JSTの時刻、秒、日付、曜日
- バッテリー残量
- 実行中タイマーのモードと残り時間
- Wi-Fi時刻同期モードの状態

`ENTER`または`SPACE`でアプリ選択ホームを開きます。ホームには次の2アプリだけを表示します。

1. Focus Wallet
2. Wi-Fi Settings

ホームで`H`を押すとロック画面へ戻ります。時計は独立したアプリとしては扱いません。

## 画面の自動消灯

最後のキー入力からの無操作時間に応じて、表示を2段階で省電力化します。

- 30秒後: バックライトを減光（輝度120から20）
- 2分後: 表示パネルをスリープさせ、ESP32-S3をLight Sleepへ移行

- Light Sleepへ入る前にCardputer ADVのES8311をミュートして最大減衰へ移行し、短い安定待ちの後にコーデックとI2Sを停止します。内部タイマーだけで一時復帰した場合は音声系を再初期化しません。
- Light Sleep中はCPU処理を停止し、ADVキーボードのTCA8418割り込み（GPIO 11）または内部タイマーで復帰します。
- 実行中タイマーがある場合は最大10秒ごと、それ以外は最大30秒ごとに内部タイマーで一時復帰し、タイマー進行、保存、日付変更、周期Wi-Fi同期を処理してから再びLight Sleepへ入ります。
- 減光中は画面表示を維持し、キー入力で通常輝度へ戻すと同時に、そのキーのアプリ操作も実行します。
- Light Sleep中のキー入力では即座にCPUと表示パネルを復帰します。最初のキー入力は画面の再表示だけに使い、アプリ操作は実行しません。
- スリープ中は画面描画の転送も停止し、復帰時に最新状態を再描画します。
- Wi-Fi接続、スキャン、NTP同期、または常時接続モードの間は無線処理を維持するためLight Sleepを保留し、LCDパネルだけをスリープします。Wi-FiがOFFになるとLight Sleepへ入ります。
- 集中、短い休憩、長い休憩、自由時間のいずれかが終了すると、自動的に通常輝度へ戻します。
- 起動直後はES8311をミュート・電源ダウン状態にします。Light Sleepからタイマー完了で復帰した場合など、停止中のスピーカーから発音する際は、再初期化直後にDACをミュートして30ms安定待ちし、ミュート解除後に本来の音を再生します。無音データは再生キューへ投入しません。
- タイマー終了による復帰時点から、無操作時間の計測をやり直します。

## Wi-Fiの標準動作

初期設定は`MODE: HOURLY TIME SYNC`です。Wi-Fiは常時接続せず、以下のタイミングだけ有効にします。

1. 端末起動時
2. 前回のNTP同期成功から1時間後
3. Wi-Fi設定画面で`C`を押して手動同期した時
4. Wi-Fiスキャンや接続設定を操作している時

接続後はNTPサーバーへ問い合わせ、実際の時刻同期コールバックを受信してから次を行います。

1. システム時刻をJSTとして利用可能にする。
2. RTC搭載機ではRTCもJSTへ更新する。
3. 次回同期を1時間後に予約する。
4. Wi-FiとSNTPを停止し、無線をOFFにする。

時刻がすでに設定済みでも、NTPの同期通知を受け取るまでは同期成功扱いにしません。

### 接続失敗

- 接続開始から15秒でタイムアウトします。
- 標準モードではWi-FiをOFFに戻し、5分後に再試行します。
- スキャン結果が0件または失敗の場合も、標準モードではWi-FiをOFFに戻します。
- SSIDが未設定の場合、自動接続は行いません。

## 常時接続モード

Wi-Fi設定画面で`A`を押すと、次のモードを切り替えます。

```text
MODE: HOURLY TIME SYNC
MODE: ALWAYS CONNECTED
```

常時接続モードでは:

- NTP同期後もWi-Fiを切断しません。
- ESP32の自動再接続を有効にします。
- 接続が失敗した場合は5分後に再試行します。
- 設定値をPreferencesの`wifi_always`へ保存し、再起動後も維持します。

常時接続をOFFに切り替えると、その場でWi-Fi無線を停止し、次の周期同期を1時間後に予約します。

## Wi-Fi設定画面の操作

| キー | 動作 |
| --- | --- |
| `A` | 周期同期／常時接続を切り替え |
| `S` | 周辺ネットワークをスキャン |
| `C` | 保存済みネットワークへ接続して時刻同期 |
| `X` | 現在の接続または処理を停止 |
| `F` | 保存済みSSID・パスワードを削除 |
| `H` | アプリ選択ホームへ戻る |

ネットワーク一覧とパスワード入力の操作はREADMEを参照してください。

## タイマー復元との関係

RTCまたは信頼できるシステム時刻がある場合は、保存時刻との差から電源断中のタイマー経過を復元します。

RTCが利用できず、実行中タイマーを復元する必要がある場合は、起動時Wi-Fi同期を待ちます。15秒以内に信頼できる時刻を取得できなければ、不正な完了判定を避けるため残り時間を保持した一時停止状態で復元します。

## 実機確認項目

- 起動直後にロック画面が表示されるか。
- `ENTER`と`SPACE`でホームを開けるか。
- ホームに時計アプリが表示されず、2アプリ構成になっているか。
- 30秒無操作後にバックライトが輝度20まで暗くなり、表示は見える状態を維持するか。
- 減光中のキーで画面が通常輝度へ戻り、そのキーの操作も実行されるか。
- 2分無操作後に表示パネルがスリープし、ESP32-S3がLight Sleepへ入るか。
- 完全消灯中の最初のキーで画面が再表示され、そのキーの操作は実行されないか。
- Light Sleep中にキーを押すとGPIO 11で即座に復帰するか。
- 効果音を一度鳴らした後でも、Light Sleep中の内部タイマー復帰に合わせた周期的なポップ音が発生しないか。
- 実行中タイマーがLight Sleep中も正しく進み、完了時刻に通常表示へ戻るか。
- Light Sleepからのタイマー完了復帰でも、3段階の完了音が最初から鳴るか。
- 周期Wi-Fi同期の時刻にタイマー復帰して接続処理を開始するか。
- ポモドーロ実行中も段階的に消灯され、タイマーが進み続けるか。
- 消灯中に集中、各休憩、自由時間が終了すると、キーを押さなくても通常輝度へ戻るか。
- タイマー終了で明るくなった後、無操作なら30秒後と2分後に再び段階的に消灯するか。
- 標準モードでNTP同期後にWi-FiがOFFになるか。
- 1時間後に再接続して時刻同期するか。
- 接続失敗後、Wi-FiがOFFになり5分後に再試行するか。
- 常時接続ONで同期後も接続を維持するか。
- 常時接続設定が再起動後も維持されるか。
